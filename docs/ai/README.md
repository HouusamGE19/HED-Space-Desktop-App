# AI-Assisted Engineering Notes

HED Space is intentionally positioned as an **AI-assisted engineering project**, not as a claim of deep Rust/Tauri specialization.

My primary development background is **Java full-stack development**, especially Java, Spring Boot, Angular, SQL, and DevOps. I used **Codex and Hermes** as coding agents to help me work effectively in a desktop stack that was outside my main area of expertise.

This folder documents the repeatable engineering process behind that work:

- [`AI-ENGINEERING-CASE-STUDY.md`](AI-ENGINEERING-CASE-STUDY.md) — how HED Space demonstrates cross-stack delivery with coding agents.
- [`AGENT-WORKFLOW.md`](AGENT-WORKFLOW.md) — the operating loop I use for agent-assisted tasks.
- [`PROMPT-PLAYBOOK.md`](PROMPT-PLAYBOOK.md) — reusable prompt patterns for investigation, implementation, review, and UI iteration.
- [`Using-Codex-CLI-Effectively.pdf`](Using-Codex-CLI-Effectively.pdf) — my practical Codex CLI field manual.

The goal is simple: **AI can accelerate implementation, but engineering judgment, verification, and responsibility stay with the developer.**
